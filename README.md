# 🌉 Personal LINE Bridge (สะพานเชื่อมแชต LINE อัตโนมัติ)

คู่มือการติดตั้งและใช้งานระบบส่งต่อข้อความระหว่างกลุ่ม A และกลุ่ม B (หรือ LINE Official Account) แบบ Real-time ด้วยความเร็วระดับ **Sub-second (< 0.2 วินาที)** พร้อมระบบถอดรหัส **E2EE (Letter Sealing)** และตัวกรองคำสั่งอัจฉริยะ

## ✨ คุณสมบัติเด่นของระบบ

* ⚡ **High-Speed Direct Polling:** ใช้เทคนิคดึงข้อความโดยตรงผ่าน `getRecentMessagesV2` ความเร็วรอบการเช็คเพียง ~139 ms (< 0.2 วินาที)
* 🔐 **Full E2EE Support:** ถอดรหัสและส่งข้อความแบบเข้ารหัสปลายทาง (Letter Sealing) อัตโนมัติ 100% พร้อม Pure-Python X25519
* 🎯 **Smart Filter & Correlation Key:** กรองเฉพาะข้อความที่มีเครื่องหมาย `#`, `$`, หรือ `%` เท่านั้น และจับคู่คำสั่งกับผลลัพธ์ตอบกลับด้วยเลขบัตรประชาชน 13 หลัก, เบอร์โทรศัพท์, หรือเลขอ้างอิง 6–18 หลัก
* 🤖 **Dual-Target Support:** รองรับปลายทาง B ทั้ง **กลุ่ม LINE (`c...`)** และ **LINE Official Account (LINE OA / บัญชีบุคคล `u...`)** โดยมีระบบ Fast-Path ยิงข้อความ Plain Text ตรงทันที
* ⏱️ **Timeout Watchdog:** ระบบตั้งเวลารอคำตอบ 90 วินาที (1.30 นาที) หากไม่มีคำตอบจากกลุ่มปลายทางจะล้างคิวคำสั่งออกอัตโนมัติ ป้องกันคิวค้าง

## 💻 ส่วนที่ 1: การติดตั้งและใช้งานบนคอมพิวเตอร์ (Windows PC)

เหมาะสำหรับเปิดใช้งานบนเครื่องคอมพิวเตอร์ทำงาน หรือรันเพื่อตั้งค่าล็อกอิน/เลือกกลุ่มครั้งแรก

### 1. ความต้องการของระบบ
* Windows 10 หรือ Windows 11
* ติดตั้ง [Python 3.10 ขึ้นไป](https://www.python.org/) (⚠️ **สำคัญ:** ตอนติดตั้งให้ติ๊กถูกที่ช่อง `"Add Python to PATH"` เสมอ)
* ติดตั้ง [Git for Windows](https://git-scm.com/)

### 2. ขั้นตอนการติดตั้งครั้งแรก
1. ดาวน์โหลดหรือโคลนโปรเจกต์ลงบนคอมพิวเตอร์:
   ```cmd
   git clone https://github.com/farn14/line-bridge.git
   cd line-bridge
   ```
2. ติดตั้งแพ็กเกจที่จำเป็น:
   ```cmd
   pip install -r requirements.txt
   pip install --no-deps CHRLINE==2.5.14
   ```

### 3. ขั้นตอนการเข้าสู่ระบบและเริ่มใช้งาน (One-Click Batch Files)

ในโฟลเดอร์โปรเจกต์ได้เตรียมไฟล์ `.bat` สำเร็จรูปไว้ให้แล้ว ดับเบิลคลิกตามลำดับได้เลย:

| ลำดับ | ไฟล์ | หน้าที่การทำงาน |
| :---: | :--- | :--- |
| **1** | **`1_LOGIN.bat`** | **ล็อกอินบัญชี LINE (คน A):** ดับเบิลคลิกเปิดไฟล์ ระบบจะสร้าง QR Code เด้งขึ้นหน้าจอให้อัตโนมัติ ยกมือถือเปิดแอป LINE แล้วสแกน พร้อมใส่รหัส PIN 4 หลัก ยืนยันตัวตน ระบบจะเซฟ Token, คีย์ E2EE, และรายชื่อกลุ่มทั้งหมดลง `config.json` ให้เอง 100% |
| **2** | **`3_CHANGE_GROUPS.bat`** | **เลือกกลุ่มต้นทางและปลายทาง:** ดับเบิลคลิกเปิดไฟล์ ระบบจะแสดงรายชื่อกลุ่มทั้งหมด ให้พิมพ์เลือกหมายเลข เช่น ต้นทาง A = `1` และ ปลายทาง B = `2` (หรือใส่ MID ของ LINE OA) ระบบจะบันทึกพร้อมใช้งานทันที |
| **3** | **`2_RUN_BRIDGE.bat`** | **เริ่มรันสะพานเชื่อม:** ดับเบิลคลิกเพื่อเปิดระบบส่งต่อข้อความ หน้าต่างจะแสดงสถานะการดักฟังแบบ Real-time |

## 📱 ส่วนที่ 2: การติดตั้งและรันบนมือถือ Android 24/7 (Termux)

เปลี่ยนมือถือ Android เครื่องเก่าที่ไม่ได้ใช้แล้ว ให้กลายเป็นเซิร์ฟเวอร์รันบอท LINE 24 ชั่วโมง **ฟรี 100%** กินไฟต่ำมาก (ประมาณ 5–10 บาท/เดือน) และเชื่อมต่อผ่านเน็ตบ้านไทยแท้ ไร้ปัญหา 403 LEGY แน่นอน

### ⚠️ ข้อควรระวังสำคัญ
> **ห้ามติดตั้ง Termux จาก Google Play Store เด็ดขาด!** เพราะเวอร์ชันใน Play Store หยุดอัปเดตไปตั้งแต่ปี 2020 และระบบ Repo ใช้งานไม่ได้ ให้ติดตั้งผ่าน **F-Droid** เท่านั้น

---

### ขั้นตอนที่ 1: ติดตั้ง Termux และขอสิทธิ์เครื่อง
1. เปิดเบราว์เซอร์ในมือถือ เข้าไปดาวน์โหลดไฟล์ APK: 👉 [https://f-droid.org/packages/com.termux/](https://f-droid.org/packages/com.termux/) (เลื่อนลงมากด **Download APK**)
2. ติดตั้งและเปิดแอป **Termux**
3. อนุญาตให้ Termux เข้าถึงพื้นที่เก็บข้อมูลเครื่อง:
   ```bash
   termux-setup-storage
   ```
   *(จะมีหน้าต่างเด้งขึ้นมา ให้กด **"อนุญาต" (Allow)**)*

---

### ขั้นตอนที่ 2: ตั้งค่ามือถือไม่ให้แอปดับ/หลับ (Critical Settings)
เพื่อให้บอทรันได้ต่อเนื่องตลอด 24 ชั่วโมง แม้จะปิดหน้าจอหรือล็อกจอไว้:

1. **สั่ง Wake-Lock ใน Termux (จำเป็นที่สุด):**
   ```bash
   termux-wake-lock
   ```
   *(จะมีแถบแจ้งเตือนเล็กๆ ค้างอยู่ด้านบนของมือถือ เพื่อล็อกไม่ให้ CPU หยุดทำงาน)*
2. **ปิดโหมดประหยัดแบตเตอรี่:**
   * ไปที่ **การตั้งค่ามือถือ (Settings)** ➔ **แอป (Apps)** ➔ ค้นหา **Termux** ➔ **แบตเตอรี่ (Battery)** ➔ เลือก **"ไม่จำกัด" (Unrestricted)**
   * ตรวจสอบว่าเปิดสวิตช์ **"อนุญาตให้ทำงานเบื้องหลัง" (Allow background activity)** แล้ว
3. **ล็อกแอปในหน้ารวมแอป (Recent Apps):**
   * ปัดเปิดหน้าสลับแอป ➔ แตะค้างที่หน้าต่าง Termux (หรือแตะไอคอนด้านบน) ➔ กดเลือกรูป **🔒 แม่กุญแจ (Lock)** ป้องกันการกดเคลียร์แรมปิดแอป
4. **การตั้งค่าเพิ่มเติมเฉพาะยี่ห้อ:**
   * **Samsung:** การตั้งค่า ➔ การดูแลอุปกรณ์ ➔ แบตเตอรี่ ➔ แอปที่ไม่เคยเข้าสู่โหมดสลีป ➔ กด `+` เพิ่ม Termux
   * **Xiaomi/POCO:** การตั้งค่า ➔ จัดการแอป ➔ Termux ➔ เปิด "เริ่มอัตโนมัติ" (Autostart) และ ตัวประหยัดแบตเตอรี่เลือก "ไม่จำกัด"
   * **OPPO/Vivo:** การตั้งค่า ➔ แบตเตอรี่ ➔ เปิด "อนุญาตให้ใช้พลังงานในเบื้องหลังสูง"

### ขั้นตอนที่ 4: สั่งรันบอท LINE Bridge บนมือถือ 🚀

```bash

```
*(หากต้องการหยุดการทำงาน ให้กดปุ่ม `Ctrl` และตัว `C`)*

#### วิธีที่ 2: รันแบบเบื้องหลัง (Background - แนะนำสำหรับการเปิด 24 ชม.)

```bash
nohup python 2_run_bridge.py > bot.log 2>&1 &
```

* **ดู Log การทำงานแบบ Real-time:**
  ```bash
  tail -f bot.log
  ```
  *(กด `Ctrl` + `C` เพื่อออกจากหน้าดู Log โดยที่บอทยังคงทำงานอยู่เบื้องหลัง)*
* **สั่งหยุดบอท (เมื่อต้องการปิด):**
  ```bash
  pkill -f 2_run_bridge.py
  ```

## ⚙️ ส่วนที่ 3: โครงสร้างไฟล์และไฟล์คอนฟิก (config.json)

ระบบจัดเก็บการตั้งค่าทั้งหมดไว้ในไฟล์ `config.json` ในโฟลเดอร์หลักของโปรเจกต์:

```json
{
  "auth_token": "eyJ0eXAiOiJKV1QiLCJhbGciOi...",
  "mid": "u2d5f38558636bb6efd8a3e261fbed8ab",
  "display_name": "⚡ N Λ K Λ ⚡",
  "e2ee_keys": {
    "keyId": "6058564",
    "privKey": "IOHoEyYrfllDGb4HBMbwTa/7PRUFIhNYuf95oPaqM1Y=",
    "pubKey": "UNbb6ItHPpfToCzhV7G0VeMLeLFSz0vlFT9lys4fJ1Q=",
    "e2eeVersion": "1"
  },
  "group_a_id": "c0f27c475ee99512b0a59a8cc43954e6a",
  "group_a_name": "ไส้เดือนน้อย(7)",
  "group_b_id": "c09377948af79c412e5647453fc60ca2d",
  "group_b_name": "Robot-10",
  "group_b_type": "GROUP",
  "timeout_seconds": 90
}
```

* `group_a_id`: รหัสกลุ่มต้นทาง A (ที่สมาชิกพิมพ์คำสั่งเข้ามา)
* `group_b_id`: รหัสปลายทาง B (กลุ่มที่มีบอท Master ตอบคำถาม หรือเป็น MID ของ LINE OA)
* `group_b_type`: รูปแบบปลายทาง (`GROUP` หรือ `OA/USER`)
* `timeout_seconds`: ระยะเวลารอคำตอบก่อนล้างคิวคำสั่งทิ้ง (ค่าเริ่มต้นคือ 90 วินาที หรือ 1.30 นาที)

## ❓ ส่วนที่ 4: การแก้ไขปัญหาที่พบบ่อย (Troubleshooting & FAQ)

### 1. ล็อกอินแล้วขึ้น `HTTP 403 Forbidden` (`x-lc: 18`)
* **สาเหตุ:** เกิดขึ้นเมื่อรันบน Cloud ต่างประเทศ (เช่น Railway, AWS US) เนื่องจาก LINE Firewall ปิดกั้น IP ของดาต้าเซ็นเตอร์นอกภูมิภาค
* **วิธีแก้:** 
  * รันบน **คอมพิวเตอร์ที่บ้าน** หรือ **มือถือ Android (Termux)** ผ่านเน็ตบ้านไทย จะไม่พบปัญหานี้ 100%
  * หากจำเป็นต้องรันบน Cloud ให้ตั้งค่า Proxy ผ่านตัวแปร `LINE_PROXY` (เช่น SOCKS5 หรือ HTTP Proxy ในไทย/เอเชีย)

### 2. บอทบนมือถือหยุดทำงานหลังจากล็อกหน้าจอไปสักพัก
* **วิธีแก้:** ตรวจสอบว่าได้รันคำสั่ง `termux-wake-lock` แล้วหรือยัง และตั้งค่าแบตเตอรี่ของ Termux ให้เป็น "ไม่จำกัด" (Unrestricted)

### 3. ต้องการเปลี่ยนบัญชี LINE คน A หรือ Token หมดอายุ
* **วิธีแก้:** ดับเบิลคลิกเปิด `1_LOGIN.bat` (บนคอม) เพื่อสแกน QR Code เข้าสู่ระบบใหม่ ระบบจะอัปเดต Token และคีย์ E2EE ลงใน `config.json` ให้อัตโนมัติ จากนั้นนำไฟล์ `config.json` ไปใส่ในมือถือ หรือสั่ง `git pull`

### 4. ข้อความแบบไหนที่บอทจะส่งต่อ?
* **เงื่อนไขต้นทาง:** ข้อความจากกลุ่ม A จะต้องมีสัญลักษณ์ `#`, `$`, หรือ `%` อย่างน้อย 1 ตัว และมีหมายเลขอ้างอิง (เช่น เบอร์โทรศัพท์ หรือเลขบัตรประชาชน 13 หลัก)
* หากเป็นข้อความคุยเล่นทั่วไปที่ไม่มีสัญลักษณ์ดังกล่าว บอทจะข้ามทันที 100% เพื่อไม่ให้รบกวนกลุ่มปลายทาง
